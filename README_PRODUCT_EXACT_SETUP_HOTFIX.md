# Scents by Aamir — Product Exact Setup + Local Crash Hotfix

## Fixed immediately

### 1. Laravel 500 crash
Wrong mega-menu route:
`ingredient.show`

Correct existing route:
`ingredients.show`

The mega menu now uses the real Phase 03 route.

### 2. 50 ML / 100 ML stock problem
The storefront now:
- prefers the first **in-stock** variant for displayed price/SKU
- sorts in-stock variants before unavailable variants
- sorts common numeric sizes from smaller to larger
- uses **50 ML** as the safe fallback when a product has no real variant rows
- no longer invents 100 ML as the PDP fallback

This is important for the current catalogue where the sellable product is commonly 50 ML.

## Exact product artwork folders

Run:

```powershell
cd E:\ScentsByAamirLaravel\frontend
php artisan storefront:prepare-product-artwork
```

or:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-product-artwork.ps1
```

To regenerate prompt/manifest files:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-product-artwork.ps1 -Force
```

The command reads the **actual imported Laravel products** and creates:

```text
public/images/products/{exact-product-slug}/
├── PROMPTS.md
├── manifest.json
├── hero.webp
├── notes.webp
├── world.webp
└── story.webp
```

The image files are intentionally not generated by the script. You generate them from each product's `PROMPTS.md` and save them with those exact filenames.

## Per-product image rules

### `hero.webp`
Bottle reference: **YES**
- upload the exact Scents by Aamir bottle
- preserve exact SBA bottle/cap/label/logo/name/proportions/liquid
- do not copy competitor packaging

### `notes.webp`
Bottle reference: **NO**
- raw note ingredients only
- based on the exact imported product notes/description

### `world.webp`
Bottle reference: **NO**
- atmospheric product world

### `story.webp`
Bottle reference: **NO**
- editorial atmosphere/story

## PDP behavior

If a product-specific asset exists, PDP now automatically uses it.

Priority:
1. `public/images/products/{slug}/hero.webp`
2. imported real Woo/Laravel product images
3. existing reusable product worlds as fallback

`world.webp`, `notes.webp`, and `story.webp` are also detected automatically.
